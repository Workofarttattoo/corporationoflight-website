# Corporation of Light Studio

A lightweight portfolio of coding, web design and motion-graphics work directed by Joshua Cole. This self-contained static project lives under `studio/`, preserving the repository's original website.

[Open the portfolio](https://workofarttattoo.github.io/corporationoflight-website/studio/)

## Run locally

From the repository root: `python -m http.server 8000`, then open `http://localhost:8000/studio/`.

No build step or third-party JavaScript dependencies. The CSV tool processes data locally. Contact links open the visitor's mail client; no form data is collected by this site. Images/video are original studio demo assets. Field Notes is fictional.

## Files

- `index.html`, `style.css`: responsive portfolio
- `demos/`: interactive examples and a Python automation download
- `assets/studio-avatar.jpg`: original generated brand avatar, not a personal portrait
- `assets/studio-motion.mp4`: original 12-second motion study
- `ADS.md`: ready-to-post copy; not evidence of actual placement
- `OPERATIONS.md`: public-safe launch instructions, scope and automation boundaries
